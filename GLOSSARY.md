# Глоссарий MonoCamera

Определения подтверждены пользователем в интервью. Открытые настройки и детали реализации сюда не включены.

| Термин | Определение |
| --- | --- |
| Профиль | Набор настроек, определяющий, как цветная сцена преобразуется в чёрно-белый кадр. Профиль сохраняется между запусками и выбирается перед съёмкой. |
| AA | Постоянный стартовый профиль. Его можно редактировать и сохранять, но нельзя удалить. Первоначальные значения AA, которые ещё предстоит определить, остаются неизменной основой для новых пользовательских профилей. |
| Пользовательский профиль | Дополнительный профиль, созданный пользователем; обозначается свободным числом от 1 до 8. |
| Цветной оригинал | Отдельное полноразмерное цветное фото того же снимка, без монохромной обработки MonoCamera. Не подразумевает RAW/DNG. |
| Чёрно-белый результат | Полноразмерный снимок, к которому применены параметры, видимые в предпросмотре в момент спуска. |
| Reset | Действие в редакторе, которое возвращает ползунки к последним сохранённым значениям текущего профиля, не меняя уже снятые кадры. |
