# Глоссарий MonoCamera

Определения подтверждены пользователем в интервью. Открытые настройки и детали реализации сюда не включены.

| Термин | Определение |
| --- | --- |
| Профиль | Набор настроек, определяющий, как цветная сцена преобразуется в чёрно-белый кадр, включая марку, ISO и силу имитации зерна. Профиль сохраняется между запусками и выбирается перед съёмкой. |
| AA | Постоянный стартовый профиль. Его можно редактировать и сохранять, но нельзя удалить. Первоначальные значения AA, которые ещё предстоит определить, остаются неизменной основой для новых пользовательских профилей. |
| Пользовательский профиль | Дополнительный профиль, созданный пользователем; обозначается свободным числом от 1 до 8. |
| Цветной оригинал | Отдельное полноразмерное цветное фото того же снимка, без монохромной обработки MonoCamera. Не подразумевает RAW/DNG. |
| Чёрно-белый результат | Полноразмерный снимок с настройками, выбранными в момент спуска. Тон и кадрирование соответствуют предпросмотру; зерно применяется при силе выше 0%, даже когда его предпросмотр выключен. |
| Двойная экспозиция | Режим создания общего изображения из двух кадров. Первый снимается в MonoCamera или выбирается из «Фото», второй снимается камерой приложения. |
| Живой предпросмотр двойной экспозиции | Показ смешивания первого кадра с текущим изображением камеры при композиции второго кадра. |
| Сила наложения | Регулировка двойной экспозиции от 0 до 100%. На 0% второй кадр полностью исключён, на 100% полностью применяется выбранный режим. В обычном смешивании 50% означает равный вклад кадров, 100% — второй кадр; для Screen и Multiply 100% означает полный эффект соответствующего режима. |
| Яркость слоя | Независимое изменение яркости первого или второго кадра при обработке двойной экспозиции в диапазоне −3…+3 ступени. Не меняет аппаратную экспозицию камеры. |
| Незавершённая пара | Состояние двойной экспозиции, в котором первый кадр уже снят или выбран, а второй ещё не снят. Первый кадр и регулировки смешивания восстанавливаются после перезапуска приложения. |
| Имитация плёночного зерна | Настраиваемая текстура с характерными для плёнки формой и размером зерна. Создаёт локальные светлые и тёмные вариации, сохраняя настройки камеры, общую яркость и тональную передачу фотографии. |
| ISO зерна | Свободная художественная шкала размера зерна от 50 до 3200, используемая совместно с выбором марки. Чем выше значение, тем крупнее зерно. Не меняет ISO камеры и не означает выбор конкретной плёночной эмульсии. |
| Сила зерна | Независимая настройка заметности текстуры от 0 до 100%. Значение 0 полностью выключает имитацию зерна; изменение силы сохраняет выбранные форму и масштаб зерна. |
| Предпросмотр зерна | Отдельно включаемый показ зерна в видоискателе. По умолчанию выключен; его состояние не определяет наличие зерна в сохраняемом снимке. |
| Reset | Действие в редакторе, которое возвращает ползунки к последним сохранённым значениям текущего профиля, не меняя уже снятые кадры. |
