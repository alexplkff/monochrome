# Образцы зерна v0.1

Изолированный эксперимент для визуального согласования D-050. Он не подключён к приложению, его профилям, видоискателю или очереди сохранения. Пользователь разрешил начать с образцов и явно выбрал программное наложение на исходное фото.

## Назначение

Предлагаемые семейства — художественные интерпретации Kodak, Ilford и Fujifilm для принятой модели «марка + свободный ISO». Это не измеренные модели эмульсий и не доказательство точного соответствия конкретной плёнке.

- Kodak: неоднородная текстура с несколькими масштабами.
- Ilford: более равномерная текстура.
- Fujifilm: более мелкая текстура при том же условном ISO.

Пользователь подтвердил структуру и диапазон размера образцов ответом «подходит» на D-050. Они служат визуальным ориентиром будущей реализации. Из-за различий плёнок внутри одной марки нельзя считать эти семейства универсальными характеристиками производителя.

ISO изменяет пространственный масштаб, а сила — амплитуду отклонений яркости. При силе 0 возвращаются исходные декодированные пиксели. Чистый чёрный и белый сохраняются; рядом с ними амплитуда ограничена доступным диапазоном. Средние отклонения балансируются по исходному уровню серого, включая поправку округления в 8 бит. Эта техника — проверяемое предложение прототипа, а не утверждённый алгоритм приложения.

Баланс средних измеряется в кодированных 8-битных серых значениях Gamma 2.2. Нулевой сдвиг в них не означает нулевого сдвига энергии в линейном свете: это разные величины. В `metrics.json` отдельно записан `linearLightMeanShiftNormalized`; численный допуск и окончательное правило компенсации пока не согласованы. Распределение яркости отдельных пикселей и локальный контраст при добавлении зерна меняются.

## Подготовка и запуск

Требуется macOS и Swift из Xcode, сторонние пакеты не нужны.

```sh
swiftc -O -module-cache-path /private/tmp/MonoGrainModuleCache prototypes/film-grain/generate.swift -o /private/tmp/monochrome-grain-samples
/private/tmp/monochrome-grain-samples /Users/alexanderpolyakov/Downloads/ava.jpg /Users/alexanderpolyakov/Desktop/icon.png prototypes/film-grain/output
```

Портрет и пейзаж — ранее предоставленные пользователем файлы. Скрипт записывает отдельные полноразмерные PNG, два сравнительных листа с оригиналом и тремя семействами при ISO 400 / силе 50%, три таблицы фрагментов для ISO 50/400/3200 и силы 25/50/100%, а также `metrics.json`.

Фрагменты вырезаются из полноразмерного результата, а не обрабатываются отдельно. На сравнительных листах и таблицах они сохраняют свои исходные размеры в пикселях; при просмотре самого листа в уменьшенном масштабе это уже не физический масштаб 100% экрана.

## Ограничения проверки

Для v0.1 генератор успешно выполнен. Во всех 30 вариантах `meanShift8Bit` и `maxTonalBinMeanShift8Bit` равны 0; максимальный `linearLightMeanShiftNormalized` составляет 0.002242 (0.2242% полного линейного диапазона). Для каждого семейства проверены рост RMS при увеличении силы и рост корреляции соседних отклонений при ISO 50 → 400 → 3200. Все пять сравнительных листов просмотрены.

Структура и диапазон размера приняты пользователем. Образцы используют разрешение исходников (портрет 685×1024, пейзаж 1024×1024); они не доказывают качество на полном фотокадре iPhone. Исходные изображения уже содержат собственную фактуру, которая сохраняется и в эталоне без добавленного зерна. Сопоставление с реальной плёнкой, производительность на iPhone и численные допуски приёмки не проверены.

Для будущего приложения ещё предстоит проверить перенос согласованного масштаба зерна на полное фото и видоискатель. Настройки по умолчанию подтверждены в D-053: Kodak, ISO 400, сила 0% для старых профилей без параметров зерна и для новых профилей.

## Проверка интеграции сборки 11

`verify-integration.swift` компилируется вместе с настоящими исходниками фильтра приложения и проверяет 18 вариантов (две сцены × три марки × ISO 50/400/3200, сила 100%), затем JPEG-экспорт 24 Мп. Его результаты отделены от принятых образцов v0.1: [метрики](integration/integration-metrics.json), [портрет Kodak/400/100%](integration/portrait-kodak-400-100.png), [пейзаж Kodak/400/100%](integration/landscape-kodak-400-100.png). Эти результаты ещё не получили визуальную приёмку пользователя.

```sh
swiftc -O -module-cache-path /private/tmp/MonoGrainModuleCache MonoCamera/Filters/FilterParameters.swift MonoCamera/Filters/FilterEngine.swift MonoCamera/Filters/FilmGrainFilter.swift MonoCamera/Camera/CameraError.swift prototypes/film-grain/verify-integration.swift -o /private/tmp/monochrome-grain-verify
/usr/bin/time -l /private/tmp/monochrome-grain-verify /Users/alexanderpolyakov/Downloads/ava.jpg /Users/alexanderpolyakov/Desktop/icon.png /private/tmp/MonoCameraGrainVerification
```

Рабочая стадия приложения использует кодированный sRGB, процедурное GPU-поле и компенсацию по 16 зонам, поэтому побитовое совпадение с CPU-прототипом не предполагается. На Apple M3 Pro максимальные абсолютные сдвиги: среднее кадра 0.03636/255, среднее зоны 0.15490/255; средняя линейная энергия sRGB 0.002049. Экспорт 4284×5712 занял 0.152 с; пик общей памяти инструмента около 891 МБ (resident set около 160 МБ). Измерения Mac не подтверждают производительность iPhone. Итоговые допуски приёмки и визуальная оценка переноса остаются открытыми.
