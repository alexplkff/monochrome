# MonoCamera

Нативная чёрно-белая камера для iPhone. Каждый спуск создаёт обработанный JPEG и отдельный полноразмерный цветной оригинал в общей медиатеке «Фото». Приложение работает локально.

## Запуск на iPhone 17 Pro

1. Откройте `MonoCamera.xcodeproj` в Xcode 26.3 или новее.
2. В настройках target `MonoCamera` выберите свою команду подписи. Если идентификатор `com.alexanderpolyakov.MonoCamera` занят, измените Bundle Identifier.
3. Подключите iPhone 17 Pro с iOS 26 или новее, выберите его как Run Destination и нажмите Run.
4. При первом запуске разрешите доступ к камере и добавление снимков в «Фото».

Видоискатель показывает целый кадр, масштабированный по ширине экрана без обрезки. Профили находятся в меню справа вверху: там можно выбрать AA или номер 1–8, создать профиль, сменить свободный номер или удалить профиль. Новый профиль всегда начинается с первоначальных настроек AA. Ползунок `EV` внизу меняет аппаратную экспокоррекцию камеры в пределах ±2 EV; он действует независимо от цветового профиля. Кнопка с ползунками открывает редактор. Изменения RGB и Contrast видны сразу, `Save` записывает их в профиль, `Cancel` отбрасывает, `Reset` возвращает последнее сохранённое состояние. Удерживайте `COMPARE`, чтобы увидеть цветной поток. Снимать можно и при открытом редакторе: кадр использует видимые настройки.

## Устройство проекта

- `MonoCamera/Camera`: AVFoundation, задняя камера 1×, видео, полноценное фото и аппаратная экспокоррекция.
- `MonoCamera/Filters`: общие параметры и один Core Image конвейер для видео и фото.
- `MonoCamera/Rendering`: MetalKit видоискатель; хранит только последний видеокадр.
- `MonoCamera/Presets`: AA и номера 1–8, версионированное локальное JSON-хранилище.
- `MonoCamera/Storage`: добавление двух независимых ресурсов в «Фото» через PhotoKit.
- `MonoCamera/Views`, `MonoCamera/App`: SwiftUI и состояние экрана.
- `MonoCameraTests`: проверки нормализации и сохранения профилей.

## Сборка и проверка

Проверенная команда сборки на этом Mac:

```sh
xcodebuild -project MonoCamera.xcodeproj -scheme MonoCamera -configuration Debug -destination 'generic/platform=iOS' -derivedDataPath /private/tmp/MonoCameraDerived CODE_SIGNING_ALLOWED=NO build-for-testing
```

Сборка приложения и тестового target прошла с Xcode 26.3 и iOS 26.2 SDK. Три теста модели и проверка фильтра на синтетическом цвете прошли на macOS. Сборка 2 подписана, установлена и запущена на iPhone 17 Pro; её новый экран и аппаратную экспокоррекцию ещё нужно проверить на устройстве. Качество пары снимков, ориентация, соответствие предпросмотра и задержка спуска также требуют проверки на iPhone. Совместимость с iOS 27 отложена по решению пользователя.

Чистые тесты моделей можно запустить на macOS без симулятора: `swift test --scratch-path /private/tmp/MonoCameraSwiftPM`. Этот пакет использует те же исходные файлы, что и iOS-приложение.

Значения AA `R=0.2126`, `G=0.7152`, `B=0.0722`, `Contrast=0` взяты из исходного ТЗ как временная техническая основа. Это не воссоздание фильтра Argentum; исходные значения AA будут уточнены пользователем.

Дополнительные объективы, RAW/ProRAW, максимальное разрешение сенсора и расширенные тональные эффекты относятся к следующим этапам. При частичном отказе сохранения успешный снимок остаётся без уведомления об ошибке, как согласовано в [протоколе решений](docs/grilling/SESSION.md).
